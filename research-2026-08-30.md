# Research — 2026-08-30

## PMF bypass
- https://github.com/domienschepers/wifi-deauthentication — WiSec 2022 paper ("On the Robustness of Wi-Fi Deauthentication Countermeasures", Schepers/Ranganathan/Vanhoef). Rogue-AP EAPOL Msg1 corruption ("invalid PMKID Tag Length in 4-Way Handshake 1/4"), full PoC bytes in `framework/test-deauthentication.py`. **No confirmed dedicated CVE** — CVE-2023-21061 was cited here previously but is wrong (verified 2026-09-01 against NVD: that ID is an unrelated Android Wi-Fi BIP-replay bug); CVE-2022-47522 was also checked and ruled out (that's the later "Framing Frames"/MacStealer transmit-queue bug). `vendor/n2-ng-v1-research/wifiresearch_80211_pmkid_wps.md` (compiled 2026-07-29, predates this note) cites the same WiSec'22 paper with no CVE attached, corroborating. Vulnerable stacks noted in the paper: hostapd 2.9/2.10 as Authenticator, Android 12 / Linux 5.15.0 as client. Scope: only clients connecting to OUR rogue AP (we'd be the Authenticator sending the corrupted Msg1).
- CSA (Channel Switch Announcement) spoofing — can hit clients on the REAL target AP. No published PoC bytes, concept only.

## Deauth tactics
- https://hackersmanifest.com/wireless-pentesting/06-deauth/
- Reason code 7 (ATWA-NG's default) = most WIDS-flagged. 3/4/8 stealthier. Not a real concern for this tool's use case.
- Disassociation (reason 8) frames — ATWA-NG has none today, only deauth.
- Only 2-5 frames actually needed for a handshake capture; ATWA-NG defaults to 64 (128 w/ bidirectional).
- mdk4 modes: `d` deauth/disassoc, `a` auth-flood, `b` beacon-flood — untested against real mdk4 CLI, sanity-check flags before use.

## WPA3 / WiFi6 / WiFi7
- https://hackersmanifest.com/wireless-pentesting/08-wpa3-wifi6/
- WPA3/WPA2 `downgrade_twin` — confirmed stub in `secure.py`, never wired up. Real gap.
- Dragonblood (CVE-2019-9494/9495) SAE timing/cache side-channel — github.com/vanhoefm/dragonblood. Nothing built for pure WPA3-SAE yet.
- OWE transition-mode downgrade — AKM suite `00-0F-AC:18`; fails if PMF-required + no transition mode.
- SAE-PK: detect via RSNXE + base32 hyphen-grouped password; defeats evil-twin outright when enforced.
- WiFi 7 MLO: enumerate per-link BSSIDs under one MLD MAC via RNR element; driver/injection support still maturing (MT7925/MT7927 most practical).
- 6GHz needs different hardware (AX210 / MT7921AU-class) than current mt76x0u/rtw88_8814au pair.
